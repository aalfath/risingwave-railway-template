# RisingWave on Railway

RisingWave v3.1.0 single-node packaged for Railway: the official image plus `psql`, an HBA config that trusts loopback and requires a password from every other address (IPv4 and IPv6), and an entrypoint that applies `RW_ROOT_PASSWORD` to the `root` user on every start.

The full template overview is published on the Railway marketplace.
